# 落ちた走行は、跡ではなく記録で見つける

> 🚨 **これは提案であって、実装していない。** 表も検査も作っていない。
> **門に載せるかも決めていない**（下の「未決」）。

## 何が起きたか（2026-08-17・同じ日に 2 件）

**どちらも「走行が途中で落ちた跡」で、落ちたことを誰も見ていなかった。**

### ① 失効し損ねたエージェントが 8 体

`packages/mcp/scripts/verify.mjs` は **最後に**後片付けをする（`【7】後片付け`）。
途中で落ちるとそこへ到達しないので、作ったエージェントが失効しないまま残る。

```
mcp-* のエージェント … 26 体（admin 13 / limited 13）
   失効済み …………… 18 体
🚨 失効していない ……  8 体   ＝ 後片付けまで到達しなかった走行
      期限切れ 6 体 ／ 🚨 まだ有効 2 体（うち 1 体は管理者権限）
🟢 対照 mcp 以外で「まだ有効」… 34 体（＝ この数え方は「在り」も出せる）
```

まだ有効だった 2 体は、司令塔の承認を得て id で失効させた（`revoked_at` を入れるだけ・行は消していない）。
🚨 **26 体のうち 8 体が落ちていた、という数を、今日まで誰も数えていない。**

### ② 常設の見本（固定の利用者）が消えていた

受入が使う固定メールの利用者が、**居なかった**。打って初めて分かった（打つ前 0 行）。

🚨 **消えた理由は分かっていない。** 誰かが消したとも、掃除のせいとも言えない。
**測っていないので、原因の場所を名指ししない。**

## なぜ気づけないのか

[[permanent-fixtures-are-not-junk]] の description に、既にこう書いてある:

> 生存を確かめる `verify:fixtures` は在るが、**どの門にも載っておらず、手で叩いたときだけ動く**

🚨 **跡は、誰かが数えに行かないと存在しないのと同じ。**
そして跡を数える形には、構造的な弱さが 2 つある。

| 弱さ | 中身 |
|---|---|
| **種類ごとに要る** | エージェント／利用者／コレクション／ポリシー … **跡の種類だけ検査が増える** |
| 🚨 **0 の意味が割れる** | 「跡が無い（正常に終わった）」と「そもそも走っていない」が**同じ 0** |

## 提案する形 — 走行そのものを 1 行にする

```
走り始め … 「この走行を始めた」を 1 行（id・時刻・何の走行か）
終わり …… その行に「終わった」を書き戻す
＝ 🚨 **始まったが終わっていない行 ＝ 落ちた走行**
```

🚨 **跡ではなく記録なので、跡の種類が増えても検査は 1 つのまま。**
🚨 **そして 0 の意味が割れない**——「走行 0 件」と「落ちた走行 0 件」は別の行として出せる。

**同じ形が既にこのリポジトリに在る**: `ohmycms_trash_purge_runs`（掃除の走行記録）。
発明ではなく、既にあるものを他の走行へ広げる話。

## 🚨 未決（**決めていないことを、決めたように書かない**）

- 🚨 **門に載せるかは決めていない。** 載せると、**跡が在るだけでコミットが止まる**。
  その痛みと釣り合うかは、担当の一存で決める範囲を超える。
- 載せるなら、出す文は「**落ちた走行が在る**」ではなく「**N 件在る（内訳つき）**」にする。
  🚨 **0 件が「異常が無い 0」だと読み手に分かるように**（[[checks-must-declare-blind-spots]] と同じ理由）。
- どの走行を対象にするか（受入・MCP の検証・掃除・その他）も決めていない。

## 🚨 似ているが別のもの

**「在るべきものが無いことに気づく形」** も要る。**これとは別物**:

| | 見つけるもの |
|---|---|
| この決定 | 🚨 **終わっていない走行が在る** |
| もう一方 | 🚨 **在るべきものが無い** |

🚨 **もう一方は、まだ案が出ていない。**
司令塔が**両方に同時に頼んだ**もので、**先に書けたのがこちらだった、というだけ**。

🚨 **「先に文書になったほうが正」にしないこと。**
向こうの案が出たときに、**この文書のほうを直す可能性がある**。
（**同じ日に「同じものを 2 つ置くところだった」を board で踏んでいる**——
片方の枠で書くと、もう片方が読み替えを強いられる。）

💭 そのうえで **同じ表に置けるかもしれない**——「走行」を主語にすれば、両方その表から引ける。
**2 つ作る前に、1 つで足りるかを見ること。**
🚨 ただし **それはこちらの見立てであって、向こうの案を見て言っているのではない。**
