# 回答フォームのデザイン規約（Zenn ベース）

> ベース: `../../zenn.md`（Zenn デザイン仕様書）。本ファイルは **回答フォームに落とすときの適用ルールと差分**だけを書く。
> 値の出典はすべて zenn.md。ここで新しい色やサイズを発明しない。

## 0. 原則

**Zenn は「読ませる」ためのデザイン。回答フォームは「選ばせる」ための画面。**
色・フォント・角丸・余白は Zenn の値をそのまま使い、**タップ領域と状態表現だけを足す**。
Zenn に無いものを足したくなったら、まず Zenn のどの部品で代用できるかを考える。

## 1. トークン（light は Zenn 実測値・dark は役割で読み替え）

| 役割 | light（Zenn 実測） | dark（本規約で定義） |
|---|---|---|
| ブランド | `#3ea8ff` | `#3ea8ff`（変えない） |
| ブランド hover | `#0f83fd` | `#6dbcff`（暗い背景では明るい方へ） |
| ブランド背景 | `#eaf4ff` | `#12283d` |
| 本文 | `rgba(0,0,0,.82)` | `rgba(255,255,255,.86)` |
| 補足 | `rgba(0,0,0,.55)` | `rgba(255,255,255,.58)` |
| 無効 | `rgba(0,0,0,.36)` | `rgba(255,255,255,.38)` |
| 罫線 | `#d6e3ed` | `#333944` |
| 背景 | `#ffffff` | `#16181c` |
| 面（カード内の面） | `#f1f5f9` | `#1e2128` |
| 危険 / 警告 / 成功 | `#f43f5e` / `#f59e0b` / `#10b981` | 同じ |

🚨 **テキスト色は必ず opacity ベース**（`#333` のような固定色にしない）。Zenn の Do。
dark でも同じ考え方で `rgba(255,255,255,.86)` を使う。

### CSS 変数について（zenn.md との唯一の意図的な差分）

zenn.md の Don't は「CSS Custom Properties に依存しない（Zenn は未使用）」だが、
**Artifact は light / dark の 2 テーマを持つ必要があるため、本規約では変数を使う。**
これは Zenn の実装を真似ないという判断であって、**見た目の値は 1 つも変えていない**。
変数は `:root` に light を全部書き、dark は `@media (prefers-color-scheme: dark)` と
`:root[data-theme="dark"]` の 2 か所で**同じトークンだけを再定義**する
（片方だけだと OS 設定とトグルのどちらかで壊れる）。

## 2. タイポグラフィ

```css
font-family: -apple-system, "system-ui", "Hiragino Kaku Gothic ProN",
             "Hiragino Sans", Meiryo, sans-serif;
```

| 用途 | サイズ | 太さ | 行間 |
|---|---|---|---|
| ページ見出し | 24px（SP）/ 32px（PC） | 700 | 1.5 |
| セクション・設問見出し | 16px | 700 | 1.6 |
| 本文・選択肢ラベル | 15〜16px | 400 / 700 | 1.8 |
| 補足・効果の説明 | 13〜14px | 400 | 1.7 |
| ラベル・件数 | 12px | 400 | 1.5 |

- **本文の行間 1.8 を崩さない**（Zenn の読みやすさの根幹）。ただし選択肢の 1 行説明は 1.7 まで詰めてよい。
- `letter-spacing` は `normal`。`palt` は当てない。
- 禁則: `word-break: break-all; overflow-wrap: break-word;`
- 数字が縦に並ぶところ（件数・進捗）は `font-variant-numeric: tabular-nums`。
- 等幅は `SFMono-Regular, Consolas, Menlo, monospace`（出力パネル・コード・ID）。

## 3. 部品

| 部品 | 値 |
|---|---|
| ボタン primary | 背景 `#3ea8ff` / 文字 `#fff` / padding `8px 24px` / radius `8px` / 16px / 700 |
| ボタン secondary | 透明 / 文字 `#3ea8ff` / 1px solid `#3ea8ff` / 同上 |
| 入力 | 1px solid `#d6e3ed`（focus は `#3ea8ff`）/ radius `8px` / padding `8px 12px` / **font-size 16px** / 高さ 40px |
| カード | 背景 `#fff` / 1px solid `#d6e3ed` / radius `12px` / padding `20px`（SP は 16px）/ 影なし |
| 影 | 1: `0 2px 4px rgba(0,0,0,.08)` / 2: `0 4px 12px rgba(0,0,0,.1)` / 3: `0 8px 24px rgba(0,0,0,.12)` |

🚨 **入力の font-size を 16px 未満にしない。** iOS Safari はフォーカス時に画面を勝手に拡大する。
Zenn の入力仕様がちょうど 16px なので、素直に従えば踏まない。

## 4. 回答フォームで足すもの（Zenn に無い部分）

| 追加 | 決め方 |
|---|---|
| **選択済みの表現** | カードと選択肢の枠を `#3ea8ff` に、背景を `#eaf4ff` に。**チェックマークを増やさない**（枠と背景で足りる） |
| **未回答 / 回答済のチップ** | 12px・角丸 99px・枠 1px。未回答は `--text-3`、回答済はブランド色 |
| **推奨バッジ** | 11px・ブランド色の枠のみ。塗らない（選択済みの塗りと混ざるため） |
| **進捗メーター** | 高さ 3px の帯 1 本。円グラフや％の大きい数字を出さない |
| **タップ領域** | 選択肢・ボタン・アコーディオンの見出しは **min-height 44px**（zenn.md §8） |

**Zenn Blue を広い面積の背景に使わない**（zenn.md の Don't）。
塗ってよいのは primary ボタンと、選択済みの薄い背景 `#eaf4ff` まで。

## 5. レイアウト

- 余白スケール: 4 / 8 / 16 / 24 / 32 / 48px。**この 6 段以外を使わない**
- 本文コンテナ: `max-width: 820px`、左右 padding は SP 16px / PC 20px
- 縦の並びは `gap` で作る（要素ごとの margin を積まない）
- ブレークポイントは **1 つだけ**: `@media (min-width: 768px)`。
  Zenn は 640 / 960 の 2 段だが、**回答フォームは中間レイアウトを持たない**ので分けない
