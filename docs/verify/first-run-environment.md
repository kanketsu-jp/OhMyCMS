### 🚨 どの測定で `asDevice("sp")` が要るか（幅依存と媒体依存を分ける）

**2026-08-16 に「SP で測ったものは全部やり直し」が配られ、そのあと絞られた**
（幅だけに依存する測定は、媒体条件と無関係なのでやり直さない）。**この画面での内訳:**

| 測るもの | `asDevice("sp")` が要るか | なぜ |
|---|---|---|
| 器の幅（`max-w-sm` = 384px） | ❌ 要らない | `max-w-sm` に媒体クエリが無い。**幅だけで決まる** |
| ロゴ欄の寸法（`min-h-20` / `max-w-64`） | ❌ 要らない | 大きさを決めているのは `file-dropzone.tsx` の `size === "logo" ? "min-h-20 w-full max-w-64" : …` の 1 行だけで、**媒体クエリを持たない**。🚨 同じファイルに `hover:` は在る（`hover:text-foreground active:text-foreground`）が、**それは色で、大きさではない** |
| 入力欄の数・区切り線の数 | ❌ 要らない | DOM の構造。媒体条件と無関係 |
| **リンクやボタンの `hover:` / `active:`** | ✅ **要る** | 🚨 Tailwind の `hover:` は `@media (hover: hover)` に包まれる。**幅だけ 390 にしても効いたまま**になり、**SP で押した手応えが出るかを測れない** |

🚨 **「SP で測った」と書く前に、その測定が媒体条件に依存するかを1行で言えるか**を確かめる。
言えないなら `asDevice("sp")` を通して、**返り値（`hover:none pointer:coarse`）を報告に出す**。

2. ⚠️ **`.next` を共有すると :3102 を壊す**。worktree を分ける理由はこれ。
   🚨 **これは踏んでいない**——worktree を分けたので試していない。**壊れることは確かめていません**。
3. 🔥 **一時ファイルをリポジトリの中に置かない**。
   `i18n` と `audit-coverage` は **staged ではなく作業ツリー全体**を見るので、
   **未追跡のまま置いてあるだけで全員のコミットが止まる**（2026-08-15 に発生）。
   計測スクリプトは scratchpad（リポジトリ外）へ。
4. 🔥 **`/tmp/xxx.txt` は他のペインと名前が衝突する**。実際に他人の出力を自分の結果として読みかけた。
   **出力は自分の scratchpad へ、実行ごとに違う名前で。**
5. 🔥 **`grep -c` と `|| echo` を使わない**（0 件で exit 1 になり、`||` が誤発火する）。
   `> file; echo "exit=$?"; wc -l < file` の形にする。
6. 🔥🚨 **画面の要素を数えるとき、`offsetParent !== null` を「見えている」と読まない。**
   **実際に踏んだ**（2026-08-15）: ステップ2 を「入力欄 2 個」と数えたが、2 個目は
   ロゴの `<input type="file">` で、**1×1px・`clip-path: inset(50%)`・`aria-hidden="true"`**。
   **人には見えない**。`sr-only` は `position:absolute` なので **`offsetParent` では消えない**。

   **除外条件（2026-08-15 に司令塔が全員で揃えたもの）:**
   ```
   次のどれかに当たる要素は、文字や個数を拾う前に外す:
     ・幅 または 高さ が 1px 以下   🚨 `> 0` では足りない（sr-only は 1×1px）
     ・clip / clip-path で潰されている
     ・aria-hidden="true" の子孫
     ・visibility: hidden / display: none
   🚨 クラス名（sr-only）だけで除かない——クラス名は変えられる。算出値で見る
   🟢 対照(+) 実在する可視の要素が 1 以上出ることを先に確かめる
   ```
   **同じ理由で `document.body.innerText` で画面の文字を数えない**（読み上げ専用の文字が混ざる）。
   この画面では実害が無かったが（ロゴ欄は `labelledBy` を使っており `sr-only` の文字を出さない）、
   **`label` prop を渡す使い方に変えた瞬間に混ざる**。
7. ⚠️🚨 **「押した」を「効いた」と読まない。** （**他ペインが 2026-08-15 に踏んだ形。私はここでは踏んでいない**） 押下を送っただけでは、
   `required` の検証で止まっていても同じ出力になる（**検証の吹き出しは DOM に残らない**）。
   **押したあとの状態を別に測る**（画面が変わったか・DB の行が増えたか）。
   この手順書の §3 は全部そうしてある（例: 「あとで」は HTTP 200 と DB の値の両方で見る）。
